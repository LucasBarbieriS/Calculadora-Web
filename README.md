Calculadora Web

Aplicação web de uma calculadora web

Funcionalidade
- **Operações Básicas**: Adição (+), subtração (-), multiplicação (×) e divisão (÷), Cálculo de raiz quadrada ($\sqrt{}$) e inversão de sinal ($+/-$).
- **Suporte a Decimais**: Permite cálculos com números de ponto flutuante.
- **Edição Rápida**: Botão de apagar o último dígito ($\dots \leftarrow$) e limpeza total do visor ($C$).
- **Tratamento de Erros**: Avisos visuais para situações inválidas, como divisão por zero.
- **Interação Completa**: Suporte para números digitados pelo teclado
- **Design Responsivo**: Responsividade para rodar em computadores e dispositivos móveis.

## Tecnologias Utilizadas
- **HTML5**: Estruturação semântica da interface.
- **CSS3**: Estilização personalizada com Flexbox e CSS Grid.
- **JavaScript (Puro, sem vue)**: Lógica de programação, controle de estados e manipulação de eventos do DOM.

## Justificativa da Escolha Tecnológica (JavaScript Puro)
A escolha por utilizar **JavaScript puro** em vez de frameworks como o Vue.js deu-se pela simplicidade 
exigidas pelo escopo da aplicação. O projeto consiste em uma calculadora com uma lógica focada em operações simples, 
sem dependências externas ou complexidade desnecessária de configuração, cumprindo requisitos de interatividade, e tambem pelo fato de eu ter mais familiaridade
com javascript puro, mesmo tendo estudado vue nas aulas, optei pelo js puro.

## Como Executar o Projeto
Não é necessário instalar nenhuma ferramenta complexa ou dependência adicional. 
1. Faça o download ou clone este repositório em sua máquina.
2. Abra a pasta do projeto.
3. Dê um duplo clique no arquivo **`index.html`** (ou abra-o diretamente em qualquer navegador web moderno como Chrome, Edge ou Firefox).
